# Calculadora Alicia: recursos educativos
Soy Cado JP, docente. Gestiono Calculadora Alicia (https://aliciacalculadoraonline.com/), una calculadora gratuita en español que muestra el procedimiento paso a paso de cada operación: sumas con llevadas, restas con préstamo, multiplicación larga, división larga, porcentajes, raíz cuadrada y álgebra.
Recursos:
- Sumas con llevadas: https://aliciacalculadoraonline.com/calculadora-de-suma/
- Restas con préstamo: https://aliciacalculadoraonline.com/calculadora-de-resta/
- Multiplicación larga: https://aliciacalculadoraonline.com/calculadora-de-multiplicacion/
- División larga: https://aliciacalculadoraonline.com/calculadora-de-division/
- Álgebra paso a paso: https://aliciacalculadoraonline.com/calculadora-de-algebra-paso-a-paso/
Sin registro, siempre gratis. Pensada para estudiantes, docentes y familias.
